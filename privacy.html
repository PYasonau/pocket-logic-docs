What this version does

Pocket Logic is a puzzle game. You do not create an account. Solving a puzzle does not require an internet connection.

This version does not show ads and does not sell in-app purchases. The Google Mobile Ads SDK and RevenueCat are not included unless real Pocket Logic identifiers are configured for a later build. This policy must be updated before that happens.

Data stored on your device

  • Puzzle marks, completed puzzles, hint counts, unlocked puzzle IDs, theme, language, reminder preference, the local dates on which you solved a puzzle, and the local dates on which you finished the puzzle of the day. Opening the app does not add a solved day.
  • A diagnostics log of up to 500 events: event name, time, and limited details such as puzzle ID, mechanic, difficulty, hint count, and paywall trigger. It does not store the puzzle grid, free text, your name, or your email. Nothing in this log is uploaded. You can clear it in Settings → View diagnostics.
  • If you turn on a reminder after completing two puzzles, the operating system stores one repeating local notification. Pocket Logic does not request a push token for this reminder.

Settings → Reset all progress deletes marks and completions on the device. It keeps the selected theme, language, and the list of puzzles unlocked with a reward. It does not clear the diagnostics log. Deleting the app removes this local data, except where the operating system keeps a backup.

Data sent off the device

The app code does not send puzzle progress, the diagnostics log, or an advertising identifier to the developer or to an analytics service. It does not request App Tracking Transparency. The Android advertising ID permission is removed from the store build.

On Android, the local-reminder library links Firebase Cloud Messaging. This build has no Firebase project configuration. The included Firebase startup provider logs an unsuccessful initialization and does not create a Firebase app when that configuration is absent. The app does not request a push token. The store build removes the advertising ID, overlay, photo and video storage, install-referrer, and launcher-badge permissions those libraries would otherwise add.

Apple and Google, as the stores that distribute the app, may process installation, purchase-of-the-app, and crash information under their own policies. Pocket Logic does not add a separate crash-reporting or analytics SDK.

Children

Pocket Logic is not directed to children under 13. The Play target audience for this version is 13 and older. The puzzles have no violence, sexual content, gambling, chat, or user posts. The store content rating is whatever the store questionnaire returns for those answers. It is not an 18+ product.

Changes

A later version that turns on ads or purchases will change this policy and the store privacy forms before that processing starts.
